# Мессенджер в СтудРаспБГТУ — предложение

Статус: черновик для обсуждения, в v1.1 не реализуется.

## Что нужно

1. Чат своей учебной группы.
2. Личные сообщения между студентами.
3. Локальный режим — общение без сервера, когда люди рядом.

Ограничение: бесплатные тарифы (Vercel Hobby + бесплатные сервисы из Vercel Marketplace).

## Почему нельзя «просто сделать на Vercel»

- Функции Vercel живут секунды–минуты и не держат постоянные WebSocket-соединения. Для «живого» чата нужен отдельный realtime-сервис.
- Опрос сервера раз в несколько секунд (polling) быстро съедает лимиты: бесплатный Neon Postgres засыпает после простоя и считает часы активной работы, а постоянные запросы от каждого открытого приложения не дают ему уснуть.

## Рекомендуемая схема

**Supabase (бесплатный тариф, есть в Vercel Marketplace)**: Postgres + Realtime (подписка на новые строки по WebSocket) + Auth в одном сервисе. Ориентиры бесплатного тарифа: ~500 МБ базы, ~200 одновременных realtime-подключений, ~2 млн realtime-сообщений в месяц; проект засыпает после недели без активности. Точные лимиты проверить перед стартом.

Vercel остаётся для веб-версии и API (модерация, жалобы, rate limit). Android и PWA подключаются к Supabase Realtime напрямую.

Альтернатива транспорта: Ably или Pusher (бесплатно ~100–200 одновременных подключений), а сообщения хранить в Neon. Сложнее: два сервиса вместо одного.

### Как уложиться в бесплатный лимит

- Срок хранения: сообщения группы — 7 дней, личные — 72 часа или до прочтения (что раньше). Удаление по расписанию через `pg_cron` в Supabase.
- Только текст до 1000 символов, без файлов и фото (их можно пересылать ссылкой на облако).
- Лимит: например, 30 сообщений в минуту с аккаунта, 500 в сутки.
- Подключение к realtime только когда чат открыт на экране; в фоне — без подписки.
- История на устройстве: приложение хранит сообщения локально (Android — SharedPreferences/Room, PWA — IndexedDB), сервер работает как «почтовый ящик» с коротким сроком хранения.

## Личность и доступ

Это главный риск: у нас нет входа через университет, поэтому любой может выбрать чужую группу.

- Вход: Telegram Login (бесплатно, у студентов он есть) или анонимный аккаунт Supabase + ник.
- Чат группы: вход по коду-приглашению, который создаёт первый участник (староста) и раздаёт в своей группе. Без кода чат группы недоступен.
- Личные сообщения: по нику или QR-коду из профиля; сначала запрос на переписку, потом чат.
- Модерация: кнопка «Пожаловаться», автоскрытие сообщения после N жалоб, бан по аккаунту.
- Шифрование личных сообщений end-to-end (libsodium) — желательно: сервер хранит только шифротекст. Ключи живут на устройстве, поэтому при переустановке старая переписка не восстановится.

## Локальный режим

- Android ↔ Android: Google Nearby Connections (Bluetooth + Wi‑Fi Direct) работает без интернета и без сервера. Подходит для «чата аудитории» на паре.
- iPhone (PWA): Safari не даёт веб-приложениям доступ к Bluetooth и Nearby, поэтому настоящий офлайн-режим на iPhone невозможен. Можно сделать «локальный» чат через WebRTC в одной Wi‑Fi сети, но для первого соединения всё равно нужен сервер-посредник.
- Итог: локальный режим — только Android; на iPhone — обычный чат через Supabase.

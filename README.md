# СтудРаспБГТУ

Расписание занятий Брянского государственного технического университета: пары по группам, преподаватели, задачи, пропуски, виджет на рабочий стол.

## Скачать для Android

**[⬇ Скачать последнюю версию (APK)](https://github.com/dbtviezy/StudRaspBGTU/releases/latest/download/StudRaspBGTU.apk)**

Все версии и список изменений — на странице [Releases](https://github.com/dbtviezy/StudRaspBGTU/releases).

Как установить:

1. Откройте ссылку выше на телефоне и скачайте файл.
2. Откройте скачанный `StudRaspBGTU.apk`. Если телефон спросит, разрешите установку из этого источника (браузера или файлового менеджера).
3. Нажмите «Установить». При обновлении данные сохраняются.

## iPhone

Веб-версия доступна по адресу **[studraspbgtu-web.vercel.app](https://studraspbgtu-web.vercel.app)**.

Чтобы пользоваться ей как приложением: откройте ссылку в Safari → «Поделиться» → «На экран Домой».

## Что нового в v1.1

- Новое название: СтудРаспБГТУ.
- Пропуск виден на карточке пары: она становится полупрозрачной, появляется плашка «Пропуск».
- «Сегодня нет» убирает пару из дня. Внизу расписания есть раздел «Скрыто» («Не хожу» и «Сегодня нет»), оттуда пару можно вернуть.
- Сброс данных удаляет всё, включая фото профиля; тема и язык сохраняются. Отдельной галочкой можно удалить файлы, скопированные в приложение.
- Рейтинг преподавателей: оценки и отзывы до 300 символов, анонимно, одна оценка с устройства. Общий для приложения и сайта.
- Исправлено: главный экран и виджет показывали не тот день.
- Исправлено: после замены аудитории «на сегодня» терялись заметки и отметки пары.
- Веб-версия для iPhone.

Полный список изменений по версиям — в [CHANGELOG.md](CHANGELOG.md).

## Версии

- `main` — только выпущенные версии, каждая отмечена тегом (`v1.0.0`, `v1.1.0`, …).
- `release/vX.Y` — работа над следующей версией; сливается в `main` при выпуске.

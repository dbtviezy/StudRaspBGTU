# Changelog

Ветки: `main` — только релизы (каждый с тегом `vX.Y.Z`), `release/vX.Y` — работа над следующей версией.

## v1.2.0 — в работе

- Приложение и сайт выглядят и работают одинаково: тот же порядок карточек в профиле, те же окна и кнопки. Внизу приложения появилась вкладка «Чаты».
- «Как читать недели» переехало в самый низ профиля, там же видно, какая сейчас неделя.
- Поиск преподавателей: сначала «Мои преподаватели» (кто ведёт у вашей группы), потом остальные. Один и тот же преподаватель больше не повторяется несколько раз — у него одна карточка со всеми предметами.
- Страница преподавателя: оценки, отзывы и ближайшие пары на одном экране. На имя преподавателя в карточке пары теперь можно нажать.
- Полный английский перевод: все экраны, подсказки, названия факультетов, аудитории и ошибки.
- Отзывы о преподавателях можно оценивать: «полезный» или «бесполезный». На отзыв можно пожаловаться.
- Аккаунт (по желанию, нужен только для чатов): логин и пароль, вход через Telegram или Google. Расписание, заметки и дела работают без входа.
- Чаты: чат группы по коду приглашения и личные сообщения по логину или ID. Без интернета сообщения сохраняются и отправляются, когда сеть появится. Сообщения группы хранятся 7 дней, личные — 3 дня.
- Чат «Рядом» (только Android): переписка с телефонами поблизости через Bluetooth и Wi-Fi совсем без интернета. Ничего не сохраняется.
- Объявления от команды на главном экране, их можно закрыть.
- Отдельное приложение для модерации «СтудРасп Админ» (вход по паролю администратора): статистика, жалобы, скрытие и удаление отзывов, удаление сообщений, блокировки по аккаунту и по телефону, объявления, список людей. Ставится рядом с обычным приложением.
- Мелочи как на сайте: плашка «Пропуск» красная в углу карточки, сегодняшний день в полосе дней выделен синим, удаление файла спрашивает подтверждение, в напоминаниях пары открываются по нажатию, язык и тема при первом запуске выбираются на первом экране, на экране ошибки загрузки есть кнопка «Повторить».
- Чаты, аккаунты, лайки, жалобы и модерация заработают после обновления сервера. До этого приложение пишет «Сервер недоступен», всё остальное работает как раньше.

## v1.1.0 — 2026-10-20

- Новое название: СтудРаспБГТУ.
- Пропуск отмечается на карточке пары: она становится полупрозрачной, появляется плашка «Пропуск».
- «Сегодня нет» убирает пару из дня. Внизу расписания появился раздел «Скрыто» с категориями «Не хожу» и «Сегодня нет», из него пару можно вернуть.
- Сброс данных удаляет всё, включая фото профиля, заметки, пропуски, задачи, скрытые пары и избранных преподавателей. Тема и язык сохраняются. Отдельная галочка удаляет файлы, скопированные в приложение.
- Рейтинг преподавателей: общая оценка, подача, строгость, лояльность и отзыв до 300 символов. Анонимно, одна оценка с устройства. Оценки общие для приложения и сайта.
- Если у пары два преподавателя, каждого оценивают отдельно.
- Исправлено: главный экран и виджет показывали не тот день. Виджет запоминал первый показанный день недели, а главный экран не обновлял дату после полуночи.
- Исправлено: после замены аудитории «на сегодня» терялись заметки и отметки пары.
- Веб-версия для iPhone (PWA): https://studraspbgtu-web.vercel.app — открыть в Safari → «Поделиться» → «На экран Домой». На Android её можно установить через Chrome («Установить приложение»).
- На странице GitHub появилась кнопка «Скачать» — всегда ведёт на последнюю версию APK.
